<目标规则>
1. 患者最新回复优先。先处理其中的新信息、情绪、困惑、抗拒、新理解或行动反馈。
2. 先判断此刻的单一目标应是关系建立/澄清、深入当前问题、从重复探索切换到实质干预、认知或行为工作、行动/实验复盘、巩固新理解，还是总结与下一步计划；只描述希望获得的患者信号，不决定实现该目标所用的策略。
3. 已有够用材料或同一问向反复出现时，应把目标转向实质干预，不换种说法继续追问。
4. turn_goal 只描述本轮希望获得的一个患者信号，不写医生话术或多轮计划；terminate=true 时只描述医生下一句的收束动作。
5. 已过去分钟数只辅助判断整体弧线，不得设置固定分钟节点，不为拖时长无效追问，也不因时间较晚跳过实质干预。
6. 风险、强情绪、抵触或问题模糊时，优先设定安全、稳定、关系修复或澄清目标。
</目标规则>

<终止规则>
1. terminate 只表示医生本句输出后是否结束当前会面，不表示当前固定会谈提纲或疗程完成。
2. 局部目标完成、轮次较多或时间较晚都不是充分条件。通常只有在本次重点明确、已进行至少一次实质治疗工作、患者形成新理解/尝试/可执行行动、必要进展达到合理程度、总结得到处理、后续行动或下次方向明确时，才可 terminate=true。
3. 若仍只有信息收集，仍在重复探索而未切换干预，患者明显困惑/抗拒尚未处理，患者刚提供关键材料尚未加工，或下一句后仍需要患者回答/选择/确认/修正，必须 terminate=false。
4. terminate=true 时，turn_goal 应要求完成不再提问的整合性总结，强化患者自己的发现并明确下一步；不得开启新目标。
5. 安全风险或患者明确要求停止时，可按安全、稳定和后续资源安排优先结束，不强求常规闭环。
</终止规则>

<输出要求>
只输出一个 JSON 对象，仅允许以下两个字段：
{
  "turn_goal": "",
  "terminate": false
}
不要输出策略、微技能、医生话术、理由、代码块或额外字段。
</输出要求>
