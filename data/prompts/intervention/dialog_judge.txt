<选择规则>
1. 候选中的英文短词是供 JSON 输出和程序校验使用的稳定 ID；括号内中文短名和说明用于理解策略。
2. primary_strategy 只输出“主要策略候选”中英文 ID，不要输出括号内中文说明。
3. micro_skill 只输出“微技能候选”中英文 ID，不要输出括号内中文说明。
4. 每轮最多选择一个主要策略和一个微技能。
5. turn_goal 只描述本轮希望获得的患者信号，不写医生话术或多轮计划。
6. terminate 只表示医生本句输出后是否结束当前会面，不表示当前固定会谈提纲完成，也不控制提纲索引。
7. 风险、强情绪、抵触或问题模糊时，遵守候选集给出的支持性和澄清边界。
</选择规则>

<输出要求>
只输出一个 JSON 对象，仅允许以下四个字段：
{
  "primary_strategy": "",
  "micro_skill": "",
  "turn_goal": "",
  "terminate": false
}
不要输出医生话术、理由、代码块或额外字段。
</输出要求>
