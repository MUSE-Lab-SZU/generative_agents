<选择规则>
1. primary_strategy 和 micro_skill 必须分别且只能从对应候选英文 ID 中各选一个，并根据患者状态和完整对话，选择最能推进当前一个必要材料缺口的组合。
2. terminate=false 时，turn_goal 只写下一轮希望获得的一个明确患者信号；terminate=true 时，turn_goal 只写医生下一句要完成的结束动作，例如简短总结、强化已形成的成果、重申防失败句、不再提问并结束本场。
3. 已知核心压力源时必须围绕该压力源推进，不得继续泛问“最近感觉怎么样”。
4. 已经获得情绪或身体感受后，应补具体情境、自动思维或它们之间的联系，不得重复身体扫描。
5. 每轮只补一个必要的材料缺口；优先使用患者已给出的具体事件、压力源、自我评价或行为入口。
6. 全部小目标都可作为当前会谈材料，不受单一活跃小目标限制。
</选择规则>

<终止规则>
1. terminate 只控制医生下一句是否作为结束性回应并在其后结束本场。
2. 如果完整对话已经满足当前提纲的 Exit Criteria，患者没有明确拒绝且当前没有 high 风险，必须设置 terminate=true；医生下一句应做不再提问的结束性总结。
3. 患者仍然低落、怀疑、保留，或在完成动作后又担心“是否算数”，不自动阻止结束。已经说出、选择、复述或实际做出的内容，不因后续同构怀疑而失效，也不得因此重新开启已完成的小目标。
4. 如果下一句仍需要患者回答、选择、确认或复述，必须设置 terminate=false。
5. 达到第 12 轮后，应更倾向于评估是否适合收束本场；这是软约束，不要求当前一轮立即结束。
</终止规则>

<输出要求>
只输出一个 JSON 对象，仅允许以下四个字段：
{
  "primary_strategy": "",
  "micro_skill": "",
  "turn_goal": "",
  "terminate": false
}
terminate 必须依据上述规则填写 true 或 false，不得把示例中的 false 当作默认答案。
不要输出医生话术、长篇推理、代码块或额外字段。
</输出要求>
