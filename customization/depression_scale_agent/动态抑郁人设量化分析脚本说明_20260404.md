# 动态抑郁人设量化分析脚本说明

## 0. 参数注入（已改为顶部集中配置）

脚本顶部新增了一组可编辑默认参数，你只需要改这里：

- `DEFAULT_ARCHIVE`
- `DEFAULT_AGENT`
- `DEFAULT_DOCTOR`
- `DEFAULT_PAIR_KEY`
- `DEFAULT_CHECKPOINTS_ROOT`
- `DEFAULT_OUTPUT_DIR`
- `DEFAULT_NO_PLOT`
- `DEFAULT_LIST_ARCHIVES`
- `DEFAULT_LIST_AGENTS`

配置完后可直接运行：

```bash
python customization/depression_scale_agent/analyze_dynamic_persona.py
```

不需要再手动在终端输入 `--archive/--agent`。

## 1. 脚本目标

脚本位置：`customization/depression_scale_agent/analyze_dynamic_persona.py`

该脚本用于根据“存档 + 角色”量化两条链路：

- `depression_dynamic_state` 的状态与数值变化（重点）。
- 强制干预对话链路效果（session 推进、锁、记录、任务积压）。

## 2. 快速使用

直接运行（使用顶部默认参数）：

```bash
python customization/depression_scale_agent/analyze_dynamic_persona.py
```

如需临时覆盖，仍可用命令行参数：

```bash
python customization/depression_scale_agent/analyze_dynamic_persona.py --archive sim-dym-severe-kbd-0404 --agent 卡布达
```

## 3. 输出文件

默认目录：`customization/depression_scale_agent/analysis_outputs/<archive>_<agent>/`

- `dynamic_state_timeline.csv`：专门看 `depression_dynamic_state`（新增重点文件）。
- `depression_state_deep_dive.png`：动态抑郁状态深度图（新增重点图）。
- `timeline.csv`：全链路时间线（动态 + 干预）。
- `events.csv`：关键跳变事件。
- `summary.md`：自动摘要。
- `persona_effect_plots.png`：干预链路四联图。

## 4. 新增“直观评分”说明

每个快照会额外给出：

- `dynamic_wellbeing_index`：0-100，越高越好。
- `dynamic_risk_index`：0-100，越高风险越高。
- `dynamic_improvement_score_vs_start`：相对首快照变化值，>0 改善，<0 恶化。
- `dynamic_improvement_status`：中文标签（显著改善/轻度改善/基本持平/轻度恶化/显著恶化）。

## 5. 建议查看顺序

1. 先看 `summary.md` 的“零、直观评分（优先看这里）”。
2. 再看 `dynamic_state_timeline.csv` 的评分列和 trigger 累计/增量列。
3. 最后看 `depression_state_deep_dive.png` 和 `persona_effect_plots.png` 做趋势确认。
