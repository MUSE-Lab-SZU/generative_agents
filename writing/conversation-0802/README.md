## 二、对话质量评估

### 2.1 评估方法

对每个 JSON 文件提取仅含 **咨询师 ↔ 来访者** 的对话（排除社交互动），计算以下指标：

| 指标 | 含义 |
|------|------|
| Avg exchanges/session | 每次咨询的平均对话轮数（一轮 = 一问一答） |
| Avg patient msg length | 来访者每条消息的平均字符数 |
| Avg counselor msg length | 咨询师每条消息的平均字符数 |
| Patient/Counselor ratio | 来访者与咨询师总字数的比值（<0.5 表示咨询师主导过多） |
| Short sessions | 对话轮数 <5 的异常短咨询次数 |

### 2.2 逐患者对比

## 五、后续注意事项

1. **KBD5 质量风险**：该患者对话参与度偏低，老师评估后如反馈"对话不真实"，需重点考虑该案例数据是否可用于正式分析。
2. **量表一致性**：附录中已嵌入系统 PHQ-9 / BDI-II 分数，老师评估后进行对比时，如出现大偏差（如老师判断为轻度而量表显示重度），需回溯对话质量。
3. **再生成**：如需更换入选 run 或恢复被排除的数据，修改 `_generate_review_doc.py` 中的 `SELECTED_RUN` 字典后重新运行即可。
